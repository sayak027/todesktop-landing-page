# ToDesktop Landing Page

A responsive landing page recreated as part of my Tailwind CSS learning journey.


## 🚀 Live Demo

[View Live Demo](https://todesktop-landingpage.vercel.app/)


## 📌 About

This project is a responsive landing page built to practice and strengthen my understanding of **Tailwind CSS**, along with HTML, CSS, and JavaScript.

The project focuses on creating a modern responsive layout with interactive navigation, animations, and FAQ sections.


## ✨ Features

- Responsive design for different screen sizes
- Mobile navigation menu
- Responsive navbar
- Scroll-based animations
- Interactive FAQ section
- Tailwind CSS utility classes
- Custom styling with CSS
- JavaScript DOM interactions
- Custom favicon


## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- CSS3
- JavaScript
- Vite / Node.js
- Vercel
